# 🪔 Diwali Sales Analysis Using Python

## 📌 Project Overview
This project focuses on analyzing Diwali sales data using Python to understand customer purchasing behavior and sales trends. The analysis includes data cleaning, exploratory data analysis (EDA), and data visualization using Python libraries.

## 🎯 Project Objectives
- Analyze customer purchasing behavior.
- Compare sales across different gender and age groups.
- Analyze state-wise orders and sales amounts.
- Explore purchasing patterns by marital status and occupation.
- Identify popular product categories and top-ordered products.
- Generate visualizations to understand sales trends.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Visual Studio Code

## 📊 Analysis Performed

### 1. Data Cleaning
- Loaded the CSV dataset using Pandas.
- Checked dataset information and missing values.
- Removed unnecessary columns.
- Handled missing values.
- Converted the Amount column to integer data type.

### 2. Exploratory Data Analysis (EDA)
- Gender-wise buyer count and sales analysis.
- Age-group-wise buyer count and sales analysis.
- State-wise order and sales analysis.
- Marital-status-wise buyer and sales analysis.
- Occupation-wise buyer count and sales analysis.
- Product-category-wise analysis.
- Top 10 products based on orders.

## 📈 Data Visualization
Created charts using Matplotlib and Seaborn to compare:
- Number of buyers by gender.
- Sales amount by gender.
- Buyers and sales by age group.
- Top 10 states by orders and sales.
- Sales by marital status and gender.
- Buyers and sales by occupation.
- Product category performance.
- Top 10 products by orders.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project

Open the project folder in Visual Studio Code.

### Step 3: Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### Step 4: Run the Python Script

```bash
python Diwali_Sales_Analysis.py
```

**Note:** Keep the CSV dataset in the same folder as the Python script.
